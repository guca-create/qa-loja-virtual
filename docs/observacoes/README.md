Severidade:

- **Crítica**: expõe dado pessoal, permite cobrança errada ou impede a compra.
- **Alta**: total, quantidade ou dado errado chega ao cliente ou ao pedido.
- **Média**: regra ausente com contorno, ou API incoerente que confunde quem integra.
- **Baixa**: texto, cosmético ou usabilidade sem impacto no dado.
